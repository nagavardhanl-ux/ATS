How it works

Applications are read as they arrive, turned into searchable records, scored against the role using weights you set, and returned as a ranked shortlist.

1

Resumes are uploaded

Applications go in as a bulk upload. PDF, DOCX and TXT are handled.

2

Everything lands in one table

Each processed resume becomes a record in the candidate dashboard. Every column has its own search, so you can filter on name, phone, email, location, date processed or the parsed summary.

3

The job description sets the scoring

Paste the job description or upload it as a file, then choose the position. Set how much skills, experience and education each count toward the score.

4

Candidates come back ranked

Each candidate returns with a match percentage, years of experience and the skills that produced the score. Shortlist, download or email from the same row.

5

Ask questions in plain language

Ask for candidates in a particular location, candidates above an experience level, or one person's resume. The answer comes back as a filtered list or a direct link to the document.

Scoring you can explain

You set the weights, not the system. Each result shows the skills that produced the score, so a shortlist can be explained candidate by candidate.

Weights are set per role, so a specialist hire and a high-volume hire are not scored on the same basis.
